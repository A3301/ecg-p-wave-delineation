# Data sources and attribution

The distributed numerical tables contain event counts, calculated statistics, and selected event times for the figure. Access the original recordings and full reference files from their publishers.

## BUT PDB

The BUT PDB counts, timing tables, and BUT PDB reference timestamps in `Figure_5_Source_Events.csv` derive from the Brno University of Technology ECG Signal Database with Annotations of P Wave, version 1.0.0, by Maršánová, Nemcova, Smisek, Smital and Vitek, published by PhysioNet. [Dataset DOI](https://doi.org/10.13026/hwvj-5b53) · [Source and CC BY 4.0 terms](https://physionet.org/content/but-pdb/1.0.0/)

The original annotations were resampled for matching at 250 Hz. The figure-event table identifies only the two windows displayed in the manuscript and distinguishes source references from model detections.

## QT Database and European ST-T

Contains information from the QT Database, version 1.0.0, which is made available under the Open Data Commons Attribution License. The external tables select the European ST-T source subset and pool paired counts by source participant. [QT Database DOI](https://doi.org/10.13026/C24K53) · [QT Database license](https://physionet.org/content/qtdb/view-license/1.0.0/) · [European ST-T source](https://physionet.org/content/edb/1.0.0/)

## Literature table

The literature comparison records source articles, protocols and reported results. Attribution follows the linked source or DOI for each comparison. Study configurations and derived scores are identified in the table.
